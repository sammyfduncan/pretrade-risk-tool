# GDELT moved from the DOC 2.0 REST API to the BigQuery public dataset on
# 2026-07-29. The REST API's binding limit is request COUNT over a multi-hour
# window, and it 429'd on the first request after a 45-minute idle wait — not
# survivable for an 8-year backfill. BigQuery serves the same corpus with no
# throttling and a 1TB/month free tier. Auth is Application Default Credentials
# (gcloud auth application-default login), NOT an API key — nothing in .env.
